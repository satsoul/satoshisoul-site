Signature Numérique SatoshiSoul

Important : La signature numérique est disponible uniquement pour les détenteurs d’une preuve SatoshiSoul existante.

Si tu n’en as pas encore, crée-la d’abord ici : Commencer une preuve.

Pourquoi la signature numérique ?

Avec ton Soul ID, tu peux maintenant prouver que le badge t’appartient vraiment, sans révéler ton identité.

Comment ça marche ?

1. Ouvre ton wallet Bitcoin (ex : Wallet of Satoshi, BlueWallet, Muun).
2. Va dans « Signer un message ».
3. Écris le message que tu veux signer.
4. Le wallet génère une signature.
5. Envoie le message + signature + ton adresse BTC publique à la personne qui doute.
6. Elle vérifie sur verify.html → "Valide ! C’est bien le propriétaire."
