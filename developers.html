Pourquoi contribuer ?

SatoshiSoul est un projet 100% open-source (licence MIT). Rejoins-nous pour construire la prochaine génération de preuves d'humanité souveraine sur Bitcoin. Que tu sois dev beginner ou expert, tes idées comptent !

Exemple : Ajoute une feature anti-deepfake, améliore l'API vérification, ou intègre de nouveaux wallets Lightning.

Notre Repository GitHub

Tout le code est disponible sur github.com/satsoul/satoshisoul-protocol. Fork, clone, et envoie une pull request !

Stack Technique Actuel

  • Frontend : HTML/CSS/JS statique (hébergé sur Netlify gratuit).
  • Paiements : Lightning Network (via LNbits ou wallets mobiles).
  • Blockchain : Bitcoin (ancrage OP_RETURN pour hashes éternels).
  • Automatisation : Zapier/n8n (pour Phase 2, traitement auto des demandes).
  • IA : DeepFace open-source (vérification anti-deepfake locale, non stockée).

Comment contribuer ?

  • 1. Fork le repo sur GitHub.
  • 2. Crée une branche (ex : feature/anti-deepfake).
  • 3. Code ta feature (en Python/JS).
  • 4. Teste localement (Replit gratuit).
  • 5. Envoie une pull request avec description claire.

Besoin d'aide ? Rejoins notre Discord ou envoie un email.

Voir aussi notre Roadmap ou White Paper pour idées. Contribue et gagne un badge Early !
